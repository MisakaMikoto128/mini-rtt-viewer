# 产品需求规格(Mini RTT Viewer)

一句话:SEGGER J-Link RTT 的极简桌面查看器——连接快、体积小、不添乱。

改需求先改这里,再改代码;测试名对应条目(`test_fr5_...`)。
状态:✔ 已实现 / ◐ 部分 / ☐ 未做 / ✖ 明确不做。

## UI/UI-x

- UI-1 左侧配置面板(连接/设备信息/接收/发送),整体可滚,内容不足时无滚动条
- UI-2 右侧日志区:等宽字体、行格滚动(逐屏行位稳定)、贴底跟随像素精确
- UI-3 搜索条浮于日志区上方,Esc 关闭,Enter 下一处
- UI-4 焦点无残留:点击空白处焦点环消失;单候选下拉不弹出

## 性能 PERF-x

- PERF-1 单二进制,release UPX 后 ≤ 4MB;启动到可连接 < 1s
- PERF-2 高吞吐流(10kHz+ 级)不卡 UI:数据路径增量处理,UI 节流合并
- PERF-3 偏好写盘节流(500ms 快照比对),退出强制落盘

## 平台 PLAT-x

- PLAT-1 **Windows 10/11 x64,仅此平台**:RTT 依赖 SEGGER J-Link 驱动 DLL
  (JLink_x64.dll;FFI 直连,不捆绑、不分发该 DLL,需用户已装 SEGGER J-Link 驱动)
- PLAT-2 兼容 J-Link V11+ 固件;pylink-square 已验证不适用(ADR-2)

## 明确不做 ✖

- Linux/macOS 支持(依赖 Windows 专属 DLL,见 PLAT-1)
- 多目标同时连接、RTT 下行通道图形化、波形绘图
- SWO/ITM、SWD 批量 Flash 烧录(交由专业工具)
- 自动更新、遥测、联网功能(本地工具,见 SECURITY.md)
