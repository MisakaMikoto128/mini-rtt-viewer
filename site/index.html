Mini RTT Viewer

SEGGER J-Link RTT 的极简桌面查看器 —— 连接快、体积小、不添乱。

下载最新版 GitHub 仓库

主界面:左侧配置面板,右侧彩色日志(深色主题)。

它是什么

单片机调试时,printf 调试依旧是最快的方式。RTT(Segger Real-Time Transfer) 比串口快得多,但官方 SWO Viewer 界面臃肿、启动慢。Mini RTT Viewer 只做一件事: 连上 J-Link,把 RTT 日志漂亮地显示出来。单文件、约 3MB、免安装。

特性

  • 直连 JLinkARM.dll(FFI),不依赖 pylink,连接即用
  • 彩色日志:ANSI/VT 全解析,深色/浅色主题,字号可调
  • 自动断帧、行尾模式、按显示列硬换行(中文/emoji 不越界)
  • 字符集切换动态生效:UTF-8 / GBK / UTF-16 LE / Latin-1 / ASCII
  • HEX 收发、定时发送、发送历史、J-Link 19 脚供电、目标复位
  • VS Code 式搜索:正则开关、命中高亮、n/m 计数、选中即搜
  • 列级选中复制(拖选即复制),日志导出,会话标记
  • 偏好全量记住:窗口、连接参数、字符集、主题,下次启动原样恢复
  • --demo-log 无设备演示模式,不接板子也能体验全部交互

快速开始

步骤说明
1. 装驱动已安装 SEGGER J-Link 驱动(JLinkARM.dll)
2. 下载Releases 下载 zip,解压即用
3. 连接选 J-Link、填芯片名(支持补全)、点连接
体验命令行运行 mini-rtt-viewer.exe --demo-log 看模拟日志流
