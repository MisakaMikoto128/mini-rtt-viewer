Mini RTT Viewer

轻量级 SEGGER RTT 日志查看器 —— 为 UTF-8 / emoji 而生。连接快、体积小、不添乱。

下载最新版 GitHub 仓库

它是什么

单片机调试时,printf 依旧是最快的排查方式。RTT 比串口快得多,但官方 RTT Viewer 界面臃肿, 而且对 UTF-8 的支持是坏的:中文乱码、emoji 直接丢失。Mini RTT Viewer 只做一件事: 连上 J-Link,把 RTT 日志漂亮地显示出来——10kHz+ 吞吐不卡 UI,启动到可连接 < 1 秒。

🖥️ 桌面版 mini-rtt-viewer.exe

Rust + Slint,单文件约 3MB,免安装,拷给同事就能用。

  • 双击即开,没有 Python 运行时、没有 WebView
  • ANSI 真彩日志、正则搜索、HEX 收发,全部本地完成
  • 数据不上网:无遥测、无自动更新

🌐 浏览器管理台 rtt-web.exe

独立小二进制,起本机服务(127.0.0.1:8686),浏览器打开即用。

  • WebSocket 实时日志流,四主题 / 发送 / 暂停 / 清空全可操作
  • 不接鼠标键盘共享的机器上,躺浏览器里看日志更舒服
  • Playwright 黑盒测试进 CI(按 spec 条目命名)

两种形态跑的是同一套数据管线(同一 worker、同一日志泵、同一设备库),功能同一水平,选顺手的用。

特性

连接与设备

  • 自动扫描本机 J-Link,多台调试器下拉选择、记住上次
  • 芯片型号输入即筛选,约 1.2 万型号自动补全
  • SWD / JTAG,速率 100–12000 kHz,RTT 通道 0–15
  • J-Link 19 脚给目标供电;目标复位:原位续收 / 断开重连
  • 连接后显示固件 / 硬件版本、序列号、核心信息

日志显示

  • ANSI 全解析:16 / 256 / RGB 真彩,颜色状态跨行跨块保持
  • UTF-8 / emoji 原样显示,跨读取块的多字节自动拼接
  • VS Code 式搜索:正则开关、命中高亮、n/m 计数、↑↓ 导航
  • 自动断帧(1–200ms 可调),按显示列硬换行(CJK 2 列、emoji 3 列)
  • 列级拖选即复制(PuTTY 惯例);暂停接收、会话标记、导出 .log
  • 滚轮逐行对齐,滚离底部失随、滚回恢复跟随

收发控制

  • HEX 收发:容忍空格 / 冒号 / 0x 前缀,开关切换时文本↔hex 双向转换
  • 定时发送 0.001–999 s,连接态才触发
  • 发送行尾 CRLF / LF / CR / 无;历史 ↑↓ 翻阅、草稿恢复
  • 字符集 UTF-8 / GBK / UTF-16 LE / Latin-1 / ASCII,切换即生效,无需重连
  • Enter 快捷发送,发送内容灰色回显

工程化

  • 四套主题:深色 / 浅色 / OLED 纯黑 / 护眼暖色,即时切换
  • 偏好全量记住:连接参数、字号、主题、窗口几何、发送历史,重启原样恢复
  • 统计栏 TX/RX 字节 + 会话时长;采集挂机屏幕常亮;单实例互斥
  • UPX 后 ≤ 4MB;fmt / clippy / test 三道 CI 门禁,clippy 零警告

快速开始

  1. 装 SEGGER J-Link 软件包 —— 程序运行时加载 JLink_x64.dll,需已安装 SEGGER J-Link 驱动(本工具不捆绑、不分发该 DLL)。
  2. 下载 —— 从 Releases 下载 zip,解压即用,无需安装。
  3. 连接 —— 选 J-Link、填芯片型号(输入即补全,如 STM32F030C8),点连接。
手头没板子?命令行运行 mini-rtt-viewer.exe --demo-log(或 rtt-web.exe --demo-log) 启动内置演示数据流:中英混排 + emoji + ANSI 颜色样例,滚动 / 断行 / 搜索 / 收发全流程随便试。

FAQ

为什么只有 Windows 版?

RTT 依赖 SEGGER 的 JLinkARM.dll,本工具用 FFI 直调该 DLL —— 它只有 Windows 版,且不捆绑分发, 需要你已装 SEGGER J-Link 软件包。不走纯 USB 协议实现,是因为那需要 Zadig 换驱动,会破坏 SEGGER 工具链的共存。 好处是与官方工具、驱动完全兼容,不抢 USB。

和官方 J-Link RTT Viewer 有什么区别?

起因就是官方对 UTF-8 的支持是坏的:中文乱码、emoji 直接丢失。这个项目从第一天起就为 UTF-8 / emoji 而生: 跨读取块的多字节序列自动拼接、按显示列硬换行(CJK 2 列、emoji 3 列不越界)、ANSI 真彩色。 其次是轻和快:单文件约 3MB、免安装、启动到可连接 < 1 秒,只聚焦"连接 + 看日志 + 发数据"。

需要准备什么?

Windows 10/11 x64 + 已安装的 SEGGER J-Link 软件包 + J-Link 调试器;目标板固件需已初始化 SEGGER RTT(SEGGER_RTT 组件)。芯片型号填写 J-Link 支持的完整型号名(如 STM32H750VB), 与官方 RTT Viewer 中的写法一致。

我的数据会上传吗?

不会。这是一个纯本地工具:无遥测、无自动更新、无任何联网功能(见仓库 SECURITY.md); 浏览器管理台也只监听 127.0.0.1 本机回环,日志数据不出你的电脑。

没有 J-Link 和板子,能先体验吗?

能。--demo-log 演示模式(桌面版和浏览器管理台都支持)会启动内置仿真数据流, 中英混排 + emoji + 颜色样例,连接 / 断开循环也会模拟——不接任何硬件就能体验滚动、断行、搜索、收发等全部交互。
